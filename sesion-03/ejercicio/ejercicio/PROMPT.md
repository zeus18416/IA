# Prompt utilizado para generar el proyecto

## Herramienta

[Lovable](https://lovable.dev) — IA generativa para desarrollo web

## Prompt

> Crea una plataforma web tipo marketplace para contratar desarrolladores de software llamada "Pixel Perfect Match". Debe incluir:
>
> - Página de inicio con hero section animada en 3D
> - Catálogo de developers con filtros por especialidad (Frontend, Backend, Full Stack, Mobile, Data, Security, Creative, AI/ML)
> - Perfiles individuales de cada developer con sus proyectos, skills, experiencia y rating
> - Sistema de comparación entre developers lado a lado
> - Página "For Companies" explicando beneficios para empresas
> - Página "For Developers" explicando beneficios para developers
> - Sección "How it Works" con el proceso paso a paso
> - Página de pricing con planes
> - Página de contacto con formulario
> - Sistema de favoritos
> - Carrusel de developers destacados
> - Internacionalización español/inglés
> - Diseño moderno, dark theme, completamente responsive
>
> Stack: React, TanStack Router, Tailwind CSS, shadcn/ui
